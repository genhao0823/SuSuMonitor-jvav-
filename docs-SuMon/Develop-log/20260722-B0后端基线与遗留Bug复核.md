
```text
Access denied for user 'susumonitor'@'localhost' (using password: NO)
SQL State: 28000
```

原因是 `metrics-validation` profile 没有提供独立数据库配置，回退到 `application.yml` 默认值：

```text
DB_NAME=susumonitor
```
