## 关键设计要点

### 1. SshTestResult interface(对齐后端 SshTestVo)

```typescript
export interface SshTestResult {
  server_id: number
  connected: boolean
  host_key_algorithm: string | null
  host_key_fingerprint: string | null
  auth_type: string
  duration_ms: number
  tested_at: string
}
```

字段与后端 `SshTestVo.java` 一一对应(snake_case by Jackson @JsonProperty)。

### 2. 7 个 SSH 错误码(与后端 ErrorCode.java 对齐)

| 错误码 | HTTP | 含义 | 前端 toast 文案 |
|---|---|---|---|
| `SSH_HOST_KEY_NOT_CONFIRMED` (40901) | 409 | 主机密钥未 trust | "请先在服务器端 trust 主机" |
| `SSH_HOST_KEY_MISMATCH` (40902) | 409 | 密钥不匹配(可能中间人) | "可能存在中间人攻击" |
| `SSH_TARGET_FORBIDDEN` (40301) | 403 | 目标地址被禁止 | "仅允许配置的网段" |
| `SSH_CONNECTION_LIMIT_REACHED` (42900) | 429 | 连接数上限 | "请稍后重试" |
| `SSH_CONNECTION_FAILED` (50002) | 502 | 连接失败 | "请检查主机端口与可达性" |
| `SSH_AUTHENTICATION_FAILED` (50003) | 502 | 认证失败 | "请检查用户名密码 / 私钥" |
| `SSH_CONNECTION_TIMEOUT` (50400) | 504 | 超时 | "请检查网络或防火墙" |

```typescript
void testSsh(id)
```
