# 终端会话生命周期实现

**日期**: 2026-07-26
**状态**: 已实现并完成 Java 回归

## 目标

在 Java 后端建立终端会话的授权、状态转换、单 JVM 配额和超时元数据收口，不处理或存储任何 PTY 内容。

## 改动

- 新增 `TerminalSessionService` 及实现。
- 每次 `terminal.open` 创建前回查 `users.review_status`；仅 `approved` 用户可创建 root 终端。
- 校验服务器存在且 Agent 为 `online`，否则拒绝创建。
- `user_id + open_message_id` 重试返回已有会话，避免重复创建。
- 单 JVM 限制：单用户 2、单服务器 4、全局 16 会话。
- 增加 20 分钟空闲超时和 8 小时最大生命周期，超时只更新会话元数据。
- 终端配置由 `TERMINAL_*` 环境变量覆盖，不包含 Shell、命令、输入输出或凭据配置。
