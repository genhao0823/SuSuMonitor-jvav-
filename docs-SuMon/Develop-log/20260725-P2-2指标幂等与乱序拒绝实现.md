# P2-2 指标幂等与乱序拒绝实现

**日期**: 2026-07-25
**范围**: Java 后端 Metrics、Agent WebSocket、Flyway、协议与 HTTP 调试样例。

## 实现内容

- 新增 `V11__create_metrics_ingestions_table.sql`，以 `(server_id, message_id)` 唯一键记录已接受的 Agent 指标消息。
- `MetricsService.report` 接收 UUID `messageId`，同一服务器的写入使用 `SELECT ... FOR UPDATE` 锁定服务器行，避免并发“先查后写”绕过时间顺序判定。
- 相同 `message_id` 的唯一键冲突静默幂等：不新增 Metrics 行，不发布 `MetricsReportedEvent`，因此不会触发 `metrics.update`、告警评估或 `alert.push`。
- 不同 `message_id` 的采样时间小于或等于该服务器最后接受采样时间时返回 `40002`，不写入指标也不发布事件。
- `metrics.report.message_id` 强制 UUID；Agent Handler 在进入 Metrics 事务前拒绝缺失或非法 UUID。
- 不新增 `metrics.report.ack`，维持单向上报和 Agent 自身重试超时语义。
