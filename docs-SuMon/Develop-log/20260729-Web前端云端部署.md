- 反向代理：宝塔 Nginx 监听 80 端口，反代 `/api/`、`/ws/agent`、`/ws/monitor` 到 `127.0.0.1:18080`

## 步骤

1. **构建修复**：
   - 现状：`src/types/terminal.d.ts` 含运行时 const，Vite build 报 `[vite:load-fallback] Could not load src/types/terminal`。
   - 处理：补充 `src/types/terminal.ts` 镜像文件；删除 `terminal.d.ts`；保留导出符号不变。
   - 影响：本仓库源码已包含修改后的 `src/types/terminal.ts`。

2. **生产构建**：

   ```text
   npm run build
   1267 modules transformed
   dist/  1.8 MB
   ```

3. **上传到云端**：

   ```text
   scp dist/index.html, favicon.jpg, tushansusu-hero.jpg, assets/ -> /www/wwwroot/susumonitor/
   chown -R www:www /www/wwwroot/susumonitor
   chmod -R 0755 /www/wwwroot/susumonitor
   ```

4. **Nginx 配置**：

   上传 `deploy/susumonitor-vhost.conf` 到 `/www/server/panel/vhost/nginx/susumonitor.conf`。

   宝塔 Nginx 主配置已包含 `include /www/server/panel/vhost/nginx/*.conf;`，重启 nginx 后 vhost 生效。

   - `phpfpm_status.conf` 已占 `server_name 127.0.0.1; listen 80;`，因此新 vhost 使用 `server_name 82.156.245.102` 不冲突。
   - 不使用 `default_server`，避免与 phpmyadmin 监听 888 冲突。

5. **重载 Nginx**：

   ```text
   /www/server/nginx/sbin/nginx -t
   syntax is ok
   test is successful
   /etc/init.d/nginx restart
   ```

## 限制

1. **明文 HTTP**：当前 80 端口不加密，浏览器访问 `http://82.156.245.102` 不会触发证书告警，但前端 `axios`/`ws` 在 HTTPS 页面下会拒绝调用。需有域名并签发证书后才做 HTTPS/WSS。
2. **没有域名**：浏览器访问 UI 时，会被解析为 IP，地址栏会显示 IP。Vue SPA 在 `/api/xxx` 相对路径下不需担心 CORS（因为同源）。
3. **Agent 验证需要 Go Agent**：`/ws/agent` 已可接受 Upgrade，下一步在 WSL 安装 Go Agent 跳 SSH 验证首帧鉴权和心跳。
4. **数据库密码策略临时 LOW**：生产部署前应恢复 MEDIUM 并使用符合策略的密码。
5. **未提供 HTTPS/WSS 验收**：仅 IPv4 无域名，无法做公网证书验收。
