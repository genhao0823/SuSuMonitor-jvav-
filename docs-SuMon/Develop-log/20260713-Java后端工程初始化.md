## 四、问题与处理

### Maven 默认 Java 版本差异

检查发现：

- `java -version` 为 Java 21。
- `mvn -version` 默认使用 Java 17。

处理方式：

- 测试时临时设置 `JAVA_HOME` 为当前 `java` 命令对应的 Java 21 路径。
- 最终 `mvn test` 使用 Java 21 执行通过。

### JDBC 字符编码配置修正

首次测试失败原因：

```text
Unsupported character encoding 'utf8mb4'
```

原因：

- `utf8mb4` 是 MySQL 字符集，不是 Java JDBC `characterEncoding` 支持的字符编码名称。

处理：

- 将 JDBC URL 中的 `characterEncoding=${DB_CHARSET:utf8mb4}` 修正为 `characterEncoding=UTF-8`。
- 数据库和建库脚本仍使用 MySQL 字符集 `utf8mb4`。
