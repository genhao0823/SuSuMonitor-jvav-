## 四、验收踩坑记录（重要经验）

1. **PowerShell 5.1 编码陷阱**：`powershell -File` 按 ANSI(GBK) 读取**无 BOM 的
   UTF-8 脚本**——中文注释乱码字节破坏解析（`switch` 对 `"start"` case 匹配异常、
   `-eq` 比较失效），表现为脚本逻辑"神秘"失效。修复：`local/rabbitmq.ps1`
   改为**纯 ASCII 注释 + if/elseif + 委托 `rabbitmq-start.cmd`**（路径含空格时
   `cmd /c` 引号截断问题的可靠绕行）。**教训：Windows 本机工具脚本保持 ASCII**。
2. **秒级 collected_at 乱序保护**：验收脚本上报间隔 <1s 时多条消息同秒，触发
   `MetricsServiceImpl` 乱序保护（`collected_at <= latest` 丢弃并回滚）。
   修复：上报时间戳递增（`nextCollectedAt`，同 verify-alert-ws）。
3. **验证库 Flyway checksum**：工作区曾出现 V2 checksum mismatch——根因是
   `target/classes` 残留了用户修改版 V2（`DATETIME(6)`，对应未提交的 V17 工作），
   增量打包未覆盖。修复：`clean package`。**教训：改 migration 前必须 clean 打包**。
