## 实现

- `afterConnectionEstablished` 将原始 `WebSocketSession` 包装为 Spring 6.2.8 `ConcurrentWebSocketSessionDecorator`，溢出策略为 `TERMINATE`。
- 新增 `TERMINAL_MONITOR_SEND_TIME_LIMIT_MILLIS`（默认 `5000`）和 `TERMINAL_MONITOR_BUFFER_SIZE_BYTES`（默认 `262144`）配置，并在 `AppProperties.Terminal` 上进行范围校验。
- `MonitorWebSocketSession.send` 统一串行出站写入，并将 Spring `SessionLimitExceededException` 转换为 `MonitorBackpressureException`。
- 新增幂等的 `MonitorSessionTerminationService`：背压时以 `monitor_backpressure` 关闭关联终端、移除订阅，并以 `SESSION_NOT_RELIABLE` 关闭浏览器会话；普通关闭维持 `monitor_disconnected`。
- 指标、告警、终端回送及 Monitor error 帧均经 `MonitorWebSocketSession.send` 发送。
