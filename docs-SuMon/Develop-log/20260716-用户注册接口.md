## 改动内容

### 新增
- 新增用户注册 Controller、业务服务、数据访问映射及对应测试。
- 新增认证模块 OpenAPI 文档和本地 HTTP 调试请求。

### 修改
- 首个注册用户自动成为 `admin/approved`，后续用户成为 `user/pending`。
- 注册密码使用 BCrypt 哈希保存，成功响应不暴露密码哈希。
- 注册时由应用生成创建时间，保证成功响应中的 `createdAt` 非空。
