# 终端中继注册表实现

**日期**: 2026-07-26
**状态**: 已实现并完成 Java 回归

## 目标

建立单 JVM 内 `session_id` 到发起终端的 Monitor WebSocket 连接的安全路由索引，为后续 Java 到 Agent 的定向下发与 Agent 响应回送提供基础。

## 改动

- 新增 `TerminalRelayRegistry`。
- 路由记录仅保存会话 ID、服务器 ID、用户已认证的 Monitor 连接引用。
- 同一会话不允许绑定到不同浏览器或服务器。
- 支持按浏览器连接或服务器批量条件移除，避免并发删除新的会话绑定。
- 不保存、输出或记录终端输入、输出、命令、Shell 环境或 Token。

## 限制

- 注册表是单 JVM 内存状态；不支持多实例路由或故障恢复。
- 本模块不连接数据库、不修改既有 WebSocket Handler，也不转发终端内容。
