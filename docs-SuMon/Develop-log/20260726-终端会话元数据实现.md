# 终端会话元数据实现

**日期**: 2026-07-26
**状态**: 已实现并完成 Java 回归

## 目标

新增终端会话元数据持久化基础，为后续生命周期和 WebSocket 中继提供会话身份、归属、状态和超时依据。

## 改动

- 新增 `V12__create_terminal_sessions_table.sql`，不修改任何已执行 Flyway 迁移。
- 保存 `session_id`、`open_message_id`、用户、服务器、状态、Shell 标识、关闭原因和时间戳。
- `(user_id, open_message_id)` 是 `terminal.open` 的幂等唯一键。
- 新增状态枚举、实体与 Mapper，提供查询、打开、关闭和活动时间更新能力。
- 表和 Mapper 不包含 PTY 输入、输出、命令、环境、凭据或 Shell 命令字段。
- 为排除数据源的 Spring/MVC 测试补充 Mapper Mock，保持测试不依赖真实 MyBatis 会话。
