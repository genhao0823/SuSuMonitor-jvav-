## 目标

将浏览器 `/ws/monitor` 的终端控制帧安全定向到对应 `/ws/agent` 连接，不记录或持久化终端内容。

- 已验证可读：`AgentWebSocketHandler.java`、`MonitorWebSocketHandler.java`、`AgentConnectionRegistry.java`。
- 本模块未删除文件，未执行数据库操作。

## 实现

- `TerminalMonitorRelayService` 处理 `terminal.open/input/resize/close`。
- `terminal.open` 使用服务端生成的会话 UUID，并绑定 Monitor 连接到目标服务器。
- 后续控制帧每次回查用户当前 approved 状态、会话拥有者和活动状态。
- Java 覆盖浏览器传入的既有会话 `server_id` 和 `session_id`，只转发持久化元数据值。
- `AgentConnectionRegistry` 使用 Agent Socket 包装器的同步写方法，避免同一连接的中继消息并发交错。
- 失败使用稳定错误码：访问拒绝、会话不存在、状态冲突或 Agent 离线。
