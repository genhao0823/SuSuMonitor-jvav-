## 教训

1. **audit-catchup v0.2 比 v0.1 强 2 倍覆盖率**:6 → 11 条规则,但同时引入更多 false positive 风险
2. **filter 函数扩展参数必要**:`filter: (val) => ...` 改成 `filter: (val, match) => ...` 给 HARDCODED_DEFAULT_PASSWORD 用作 placeholder 上下文排除
3. **auto-imports.d.ts 必须 exclude**:自动生成文件不该被审计扫,excludeFile 是必要防线
4. **LONG_FILE 不算 bug,只是建议**:作为 INFO 严重度,让开发者主动决定要不要拆
