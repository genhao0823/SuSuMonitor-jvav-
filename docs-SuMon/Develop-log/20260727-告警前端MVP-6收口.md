## 关键设计决定

| 决策 | 选型 |
|---|---|
| 类型命名 | 不带 `Vo` 后缀，与现有 `Server` / `SshTestResult` 风格一致 |
| API 模块 | 新建 `src/api/alert.ts`，6 个 REST 函数 + `isAlertPush` 类型守卫 |
| 状态层 | 新建 `src/stores/alerts.ts`，**非持久化**（REST 始终为真源） |
| WS 客户端 | **复用并最小扩展** `MonitorWebSocket`（新增可选 `onAlertPush` 回调 + `currentServerId` getter + disconnect 时发送 `metrics.unsubscribe`） |
| alert.push 订阅触发 | **只在告警记录页选择具体 server_id 后订阅**；切换筛选先 unsubscribe，离页同样 disconnect |
| 数据真源 | REST 列表 = 真源；WS = 顶部"有 N 条新告警"轻提示（用户点刷新才拉取，不自动刷） |
| 路由 | `/alerts/records`（requiresAuth）、`/alerts/rules`（requiresAuth + requiresAdmin） |
| 范围外（明确不做） | 全局 toast、Dashboard 角标、未读数徽标、批量审核、ECharts、Android、xterm.js |
