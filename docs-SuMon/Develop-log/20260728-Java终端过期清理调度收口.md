# 2026-07-28 Java 后端终端过期清理调度收口

## 范围

本阶段直接在 `main` 分支收口终端过期清理调度，不改变终端会话清理业务规则：调度器只触发 `TerminalSessionService.closeExpiredSessions()`，不复制清理逻辑。

默认配置：

```yaml
susumonitor:
  terminal:
    cleanup-cron: ${TERMINAL_CLEANUP_CRON:0 0 * * * ?}
```

配置已覆盖主配置、生产 profile 和测试 profile。生产环境可通过 `TERMINAL_CLEANUP_CRON` 覆盖，默认每小时执行一次。

## 异常和状态语义

- 单轮清理异常记录日志，不向 Spring 调度线程继续抛出。
- 清理服务继续只扫描活动终端会话。
- 空闲超时和最大会话时长超时统一更新为 `timeout`。
- 已关闭、已超时或错误会话不重新处理。
- 清理后的会话不再占用终端活动配额。
