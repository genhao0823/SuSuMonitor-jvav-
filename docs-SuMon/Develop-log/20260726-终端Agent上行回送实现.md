# 终端 Agent 上行回送实现

**日期**: 2026-07-26
**状态**: 已实现并完成 Java 回归

## 目标

将 Agent 的 `terminal.opened/output/closed/error` 响应安全回送至发起该会话的唯一 Monitor WebSocket 连接。

## 实现

- 新增 `TerminalAgentRelayService`。
- 校验 Agent 终端消息载荷、认证连接的 server ID 与 payload server ID 一致。
- 校验 `session_id` 的内存绑定归属同一服务器，阻止跨服务器伪造响应。
- `terminal.opened` 将持久化会话从 `opening` 原子切换到 `open`。
- `terminal.closed` 持久化关闭状态，并在消息成功回送后移除内存路由绑定。
- Monitor WebSocket 会话使用串行发送，避免输出帧和指标推送交错。
- 不记录或持久化 PTY 输入、输出、命令、Shell 环境或 Token。
