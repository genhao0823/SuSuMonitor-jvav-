# Apifox SSH 50003 真实验收

## 目标

执行 Apifox 测试用例 `397636440`，验证独立受控 SSHD 上的错误密码认证路径返回 HTTP `502` 和业务码 `50003`。

## 隔离边界

- 独立 OpenSSH 仅监听 `127.0.0.1:2223`，未修改系统 SSH 配置。
- Spring Boot 后端仅在验收进程内监听本机 `18080`，进程结束后停止。
- 管理员与 SSH 测试凭据从当前 Windows 用户环境变量读取。
- 管理员 JWT 由登录接口在运行时签发，只在验收进程内传给 Apifox CLI。
- JWT 不写入 Git、Apifox 持久化变量、项目配置或本文档。

## 运行结果

Apifox 项目和用例：

```text
项目：8585366
分支：ai/20260725-from-main-ssh-50003-validation
用例：397636440
名称：J6 SSH wrong password returns 50003
```

用例真实执行两次，分别输出 JSON 和 JUnit：

```text
JSON：j6-ssh-50003-json.json
JUnit：j6-ssh-50003-junit.xml
```

JUnit 报告结果：

| 断言 | 结果 |
|---|---|
| HTTP status is 502 | 通过 |
| Business code is 50003 | 通过 |
| Message is ssh authentication failed | 通过 |
| X-Request-ID exists | 通过 |

JSON 报告结果为 `passed=1`、`failed=0`。原始报告中的运行时 JWT 已替换为 `[REDACTED_JWT]` 后才保留。

## 清理验证

本轮曾创建三条临时服务器记录，用于修正和完成受控验收。三条记录均仅通过 `DELETE /api/servers/{id}` 软删除，数据库复核结果如下：

```text
records=3
deleted=3
deleted_at_not_null=3
delete_token_not_null=3
```

验收结束后确认：

- `18080` 未监听。
- `2223` 未监听。
- 临时 SSHD 目录和临时 RSA 私钥不存在。
- 脱敏 JSON/JUnit 报告不含 JWT 或 SSH 私钥。

## 验证边界

本次覆盖的是错误密码认证失败路径，不覆盖真实连接阶段失败 `50002`。该路径已经证明主机指纹确认成功后，SSH 用户认证失败会映射为 HTTP `502`、业务码 `50003`。
