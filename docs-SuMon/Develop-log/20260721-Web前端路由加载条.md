## 关键设计要点

- **零状态管理**:NProgress 是全局命令式 API,不走 Vue 响应式。
  不需要 `ref` / `reactive` / `watch`。
- **依赖最少**:`nprogress` ~3KB 无依赖,`@types/nprogress` 仅类型声明。
  比 vue-loader / suspense / top-progress 等同类方案轻。
- **自动注入 DOM**:`nprogress.css` 提供 `<div id="nprogress">` 容器 + 进度条元素。
  无需在 App.vue 写额外模板。
- **主题色与全站一致**:玫红 `#ff5b8a → #b7325c` 与 Dashboard 渐变徽标、AuthLayout 主色同源。

## 已知限制

- NProgress 不支持 SPA 内部 lazy load / 异步组件加载完成事件(只在路由切换的 beforeEach 触发)
- 进度条无法反映数据请求时长(只有路由切换那 ~100ms)
- dark mode 下 `.bar` 颜色保持不变,如需暗色适配,可在 CSS media query 中覆盖

## 风险与对策

| 风险 | 处理 |
|---|---|
| NProgress 注入 DOM 与 SPA 路由切换时序冲突 | NProgress 在 beforeEach(start)/afterEach(done) 完全在路由生命周期内,无冲突 |
| `useRouterLoading` 模块顶层执行,HMR 不会重新跑 | 改完 router/index.ts 后需硬刷新页面一次;之后 HMR 正常 |
| CSS 主题与全站其他渐变不一致 | 复用 `#ff5b8a → #b7325c`,与 Dashboard / AuthLayout 同色板 |
