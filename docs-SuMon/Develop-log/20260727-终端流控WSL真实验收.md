# 开发日志: 终端流控 WSL 真实验收

**日期**: 2026-07-27
**操作人**: OpenCode

## 验收范围

- 目标服务运行于隔离库 `susumonitor_metrics_validation`，未操作正式库 `susumonitor`。
- WSL Ubuntu 使用 `/opt/go/bin/go` 1.23.0 构建短生命周期 Linux Agent 与流控运行器。
- Java 服务仅监听本机验收端口 `18081`；每个场景使用独立 Java 进程和随机运行时 JWT/AES 密钥。
- 运行器创建临时 Server 和 Agent Token，退出时停止 Agent 并撤销临时 Agent Token。
- 不记录数据库密码、应用密码、JWT、Agent Token、PTY 输入、PTY 输出或实际内部地址。

## 实现与修正

### 新增

- 新增 `agent-go-SuMon/cmd/terminal-flow-control-integration/main.go`，覆盖 baseline、Java 输出限流与有限 Monitor 背压尝试。
- 新增 `scripts/run-wsl-terminal-flow-control-integration.sh`，每次在当前 WSL 会话构建权限为 `0700` 的临时二进制，并交互读取应用管理员凭据。
- 新增 `scripts/start-terminal-flow-control-java.ps1`，每次启动前打包当前 Java 源码，交互读取隔离 MySQL 凭据，并只在当前 PowerShell 进程设置运行时配置。
- 新增 `scripts/prompt-password.ps1`，通过 `Read-Host -AsSecureString` 读取 PowerShell 密码输入。

### 修正

- 发现旧 JAR 会将合法 `terminal.open` 作为未知消息返回 `40000`。启动脚本现先执行 `mvn.cmd -q -DskipTests package`，再启动 JAR，避免运行过期构件。
- Agent 验收心跳间隔由 `2s` 调整为 `5s`，与 Java 默认 Agent 心跳限流 `12/min`、突发 `3` 一致，避免通用 `42902` 干扰终端控制帧验收。
- 控制帧洪泛量调整为 `180`。Java 输入桶为 `600/min`、突发 `120`，传输期间会持续补充令牌；`180` 可稳定越过突发容量与补充量并观察 `42904`。
- 移除验收期间加入的阶段输出、Agent 日志回显与非目标帧计数；保留服务端稳定错误码诊断。

## 实际结果

### 已真实通过

| 场景 | Java 场景参数 | 观察结果 |
| --- | --- | --- |
| baseline | Java 输出预算 `1 MiB/s`、突发 `1 MiB` | 通过。确认 Monitor 控制帧限流 `42904`、Monitor 断连收口、Agent 断连收口，以及 Go Agent PTY 输出超额关闭原因 `output_rate_exceeded`。 |
| Java 输出限流 | Java 输出预算 `1 B/s`、突发 `16 KiB`；Agent 输出预算保持高值 | 通过。确认 Java 侧输出限流移除中继绑定，后续有效控制帧返回 `40903 TERMINAL_SESSION_STATE_CONFLICT`。 |

### 未真实覆盖

| 场景 | 已执行操作 | 边界与结论 |
| --- | --- | --- |
| Monitor 慢消费者背压 | 启动 `TERMINAL_MONITOR_BUFFER_SIZE_BYTES=1024` 的隔离服务；在 WSL 中保持终端所属 Monitor 不读取，并请求最多 `64 MiB` 无敏感输出。 | 未观察到 WebSocket `1012 SESSION_NOT_RELIABLE`。WSL loopback 与本机 TCP 缓冲持续吸收串行 Agent 输出，未形成 `ConcurrentWebSocketSessionDecorator` 所需的发送积压。不能将该路径标记为真实通过。 |
| `monitor_backpressure` 元数据持久化 | 无公开终端会话元数据查询接口。 | 无法在运行器中端到端读取关闭原因，未完成真实持久化确认。 |

当前项目预期用户数不超过五人，正常终端输出几乎不会持续达到极大规模。未使用 `1 GiB` 输出强行制造本机 loopback 背压，也未为验收目的修改生产发送模型。现有背压实现仍由单元测试覆盖；如需真实覆盖，应在可控网络限速或实际慢客户端环境中执行。
