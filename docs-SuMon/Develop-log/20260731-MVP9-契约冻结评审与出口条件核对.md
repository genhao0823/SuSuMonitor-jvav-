## 四、性能基线评审结论

- 7 场景全部 PASS，正确性断言全过（记录数、推送数、幂等命中率、投递数）。
- 关键发现：**规则数放大效应（S1→S2 延迟 +45ms p50）根因是每规则一次状态查询**，已作为 MVP-11 优化点登记（见基线文档 §10.1-1）。
- 环境限制（开发模式 JVM、C1 编译）已在文档 §9.1 记录，数字仅作同口径回归基线。

## 五、MVP-9 未纳入/未验证项（继续留痕，不宣称完成）

1. RabbitMQ 运行时（Exchange/Queue 声明、Confirm/Return、Outbox 补发、ACK/重试/DLQ）——MVP-10/MVP-11。
2. 多 JVM 跨实例 AFTER_COMMIT 事件广播——依赖 Redis 或消息队列，MVP-10+。
3. DB 单语句耗时单独测量（performance_schema）——留作可选辅助项。
4. 生产 JVM 参数（-Xms/-Xmx、C2 编译）下的重测——待云端部署后按同口径补测。
