## 实现

- 新增 Maven Wrapper，固定下载 Maven `3.9.9`，供 Java 21 后端使用 `./mvnw` 或 `mvnw.cmd` 构建。
- 新增 `application-prod.yml`：生产 Profile 使用 INFO/WARN 日志、回环监听、Nginx 转发请求头处理、回环可信代理 CIDR 和 HTTPS CORS 默认占位值。
- 新增 `deploy/susumonitor-server.env.example`：只包含占位符，约定实际环境文件为 `/etc/susumonitor/server.env`、`root:root`、`0600`。
- 新增 `deploy/susumonitor-server.service`：Java 使用 `susumonitor` 专用非 root 用户运行，固定 `-Xms256m -Xmx768m`，读取仓库外环境文件，并以 journald 收集日志。
- 新增 Nginx 合并片段：提供 SPA fallback、`/api/`、`/ws/agent` 和 `/ws/monitor` 反代；WebSocket 读写超时均为 `3600s`。
- 新增部署手册：明确上线前确认、数据库备份可读验证、Flyway 向前迁移、健康检查、升级和数据库回滚边界。
