# 终端中继断连收口实现

**日期**: 2026-07-26
**状态**: 已实现并完成回归

## 目标

在浏览器或 Agent WebSocket 断开时清理内存路由、收口终端会话元数据并尽量关闭远端 PTY。

## 实现

- 新增 `TerminalRelayLifecycleService`。
- Monitor 断开时：移除其会话绑定，向在线 Agent 发送服务端生成的 `terminal.close`，并将元数据标记为 `closed/monitor_disconnected`。
- Agent 断开时：仅当该连接仍是服务器当前连接，才移除关联会话并标记为 `error/agent_disconnected`。
- Agent 重连替换旧连接后，旧连接的关闭回调不会关闭新连接承载的终端会话。
- 修正可选 `session_id` 的 Agent `terminal.error`：无关联会话时不错误拒绝，也不广播给无归属浏览器。
