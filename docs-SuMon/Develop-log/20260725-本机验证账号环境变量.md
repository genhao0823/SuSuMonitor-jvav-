# 本机验证账号环境变量

## 目的

本机受控 SSH、Apifox 和 API 验收使用独立测试账号。凭据仅保存在当前 Windows 用户的环境变量中，不写入 Git、项目配置、Apifox 持久化环境、测试报告或开发日志。

## 已设置变量

| 环境变量 | 用途 | 作用域 |
|---|---|---|
| `SUSUMONITOR_VALIDATION_ADMIN_USERNAME` | 本机 API 和 Apifox 验收管理员用户名 | 当前 Windows 用户 |
| `SUSUMONITOR_VALIDATION_ADMIN_PASSWORD` | 本机 API 和 Apifox 验收管理员密码 | 当前 Windows 用户 |
| `SUSUMONITOR_VALIDATION_SSH_USERNAME` | 独立受控 SSHD 的测试用户名 | 当前 Windows 用户 |
| `SUSUMONITOR_VALIDATION_SSH_PASSWORD` | 独立受控 SSHD 的测试密码 | 当前 Windows 用户 |

管理员账号仅用于本机验证，并以 `admin` 和 `approved` 状态创建。SSH 测试身份必须受本机验证环境控制，不得使用系统管理员、生产账号或项目成员账号；错误密码验收不会使用该身份完成认证。

## 使用方式

新的终端窗口会读取用户范围变量；已打开的终端需要重新打开，或在当前 PowerShell 会话中读取用户范围变量：

```powershell
$env:SUSUMONITOR_VALIDATION_ADMIN_USERNAME = [Environment]::GetEnvironmentVariable('SUSUMONITOR_VALIDATION_ADMIN_USERNAME', 'User')
$env:SUSUMONITOR_VALIDATION_ADMIN_PASSWORD = [Environment]::GetEnvironmentVariable('SUSUMONITOR_VALIDATION_ADMIN_PASSWORD', 'User')
$env:SUSUMONITOR_VALIDATION_SSH_USERNAME = [Environment]::GetEnvironmentVariable('SUSUMONITOR_VALIDATION_SSH_USERNAME', 'User')
$env:SUSUMONITOR_VALIDATION_SSH_PASSWORD = [Environment]::GetEnvironmentVariable('SUSUMONITOR_VALIDATION_SSH_PASSWORD', 'User')
```

Apifox CLI 运行时变量仅从当前进程读取，不将变量值写入 Apifox 项目或环境。管理员 JWT 应在运行前由登录接口获取，不能持久化为用户环境变量。

## 安全约束

- 禁止通过命令行参数传递密码或 JWT。
- 禁止将凭据写入 `.env`、JSON、YAML、PowerShell 脚本、测试报告或文档。
- 验收日志只记录变量是否存在、HTTP 状态、业务码和脱敏后的结果。
- 临时 SSHD、测试用户、临时服务器记录和运行时 JWT 在验收结束后清理；服务器记录只能通过业务接口软删除。
- 如需更换凭据，生成随机密码后调用 `[Environment]::SetEnvironmentVariable` 覆盖用户范围变量，不要在项目中记录旧值或新值。

## 验证

仅验证变量存在，不输出值：

```powershell
$names = @(
    'SUSUMONITOR_VALIDATION_ADMIN_USERNAME',
    'SUSUMONITOR_VALIDATION_ADMIN_PASSWORD',
    'SUSUMONITOR_VALIDATION_SSH_USERNAME',
    'SUSUMONITOR_VALIDATION_SSH_PASSWORD'
)

foreach ($name in $names) {
    $present = -not [string]::IsNullOrWhiteSpace([Environment]::GetEnvironmentVariable($name, 'User'))
    "${name}: $present"
}
```
