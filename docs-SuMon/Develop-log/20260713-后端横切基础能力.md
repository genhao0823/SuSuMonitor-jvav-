## 一、目标

实现 MVP-1 的第一批后端基础能力，让 Java 后端具备可通过 Apifox 调用的最小系统接口闭环。

## 二、改动内容

### 统一响应和错误码

新增文件：

- `server-java-SuMon/src/main/java/com/susumonitor/server/common/ApiResponse.java`
- `server-java-SuMon/src/main/java/com/susumonitor/server/common/ErrorCode.java`
- `server-java-SuMon/src/main/java/com/susumonitor/server/common/BusinessException.java`
- `server-java-SuMon/src/main/java/com/susumonitor/server/common/GlobalExceptionHandler.java`

实现内容：

- 统一成功响应结构：`code`、`message`、`data`。
- 统一错误响应结构：`code`、`message`、`data`。
- 第一批错误码：`0`、`40000`、`40002`、`50000`、`50001`。
- 全局异常处理，避免接口直接返回 Spring 默认错误结构。

### request_id

新增文件：

- `server-java-SuMon/src/main/java/com/susumonitor/server/common/RequestIdFilter.java`

实现内容：

- 支持透传请求 header `X-Request-ID`。
- 请求未携带时自动生成 UUID。
- 响应 header 返回 `X-Request-ID`。
- 写入日志 MDC key：`request_id`。
- 请求结束后清理 MDC。

### 系统接口

新增文件：

- `server-java-SuMon/src/main/java/com/susumonitor/server/module/system/controller/SystemController.java`
- `server-java-SuMon/src/main/java/com/susumonitor/server/module/system/vo/HealthStatusVo.java`
- `server-java-SuMon/src/main/java/com/susumonitor/server/module/system/vo/ReadyStatusVo.java`

实现接口：

- `GET /api/health`：应用存活检查，不依赖数据库。

## 四、Apifox 测试说明

1. 在 Apifox 中导入 `docs-SuMon/OpenApi-SuMon/openapi-system.json`。
2. 设置环境地址为 `http://localhost:18080`。
3. 启动后端后调用 `GET /api/health`。
4. 检查响应状态码为 200，响应体 `code = 0`，`data.status = UP`。
5. 检查响应 header 包含 `X-Request-ID`。
6. 调用 `GET /api/ready`。
7. 本机 MySQL 可连接时应返回 `code = 0` 和 `data.database = ok`。
8. 本机 MySQL 不可连接时应返回 HTTP 500 和 `code = 50001`。
