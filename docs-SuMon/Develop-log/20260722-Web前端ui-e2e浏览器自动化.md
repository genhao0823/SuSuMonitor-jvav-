## 关键设计要点

- **puppeteer-core 而非 puppeteer**:不下载 chromium(~150MB),用系统 Chrome
- **headless: 'new'**:更接近真实 Chrome 行为
- **page.keyboard.type + delay: 50**:Element Plus v-model 需要每个字符的 input 事件有时间传播,不加 delay 会导致 v-model 不收到值
- **networkidle0 -> domcontentloaded**:Vite HMR 的 websocket 会让 networkidle0 永远不满足
- **localStorage 清空 fallback**:头像下拉点不到时,直接 `localStorage.clear()` + goto /login
