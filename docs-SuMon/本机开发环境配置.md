# 本机开发环境配置

**适用范围**: 当前 Windows 主机本机开发和调试  
**后端目录**: `server-java-SuMon/`  
**后端端口**: `18080`

## 一、当前环境约定

| 项 | 当前值 |
|----|--------|
| 操作系统 | Windows |
| 后端语言 | Java 21 LTS |
| 后端框架 | Spring Boot 3.x |
| 构建工具 | Maven |
| 数据库 | MySQL 8.4 |
| 数据库服务名 | `MySQL84` |
| 数据库地址 | `127.0.0.1:3306` |
| 数据库名 | `susumonitor` |
| 数据库用户 | `susumonitor` |
| 本机开发数据库密码 | `732682` |
| 字符集 | `utf8mb4` |
| 排序规则 | `utf8mb4_unicode_ci` |

## 二、MySQL 初始化

本机 MySQL 初始化脚本：

```text
scripts/local-mysql-init.sql
```

脚本职责：

- 创建数据库 `susumonitor`。
- 创建本机开发用户 `susumonitor@localhost`。
- 创建本机开发用户 `susumonitor@127.0.0.1`。
- 授权 `susumonitor` 用户访问 `susumonitor` 数据库。
- 刷新 MySQL 权限。

说明：

- 该脚本只用于本机开发。
- 业务表结构后续由 Java 后端 Flyway 迁移脚本管理。
- 生产环境不得使用本机开发密码 `732682`。

## 三、后端启动

Java 后端工程尚未初始化，后续以后端实际工程为准。

目标启动目录：

```text
server-java-SuMon/
```

目标验证命令：

```bash
curl http://localhost:18080/api/health
curl http://localhost:18080/api/ready
```

`/api/ready` 应检查数据库连通性，数据库正常时返回 `database=ok` 或等价成功响应。

## 四、环境变量规划

后续 Java 后端应支持以下环境变量或本机配置项。

应用配置：

| 配置项 | 示例 | 说明 |
|--------|------|------|
| `APP_ENV` | `local` | 当前运行环境 |
| `APP_NAME` | `susumonitor` | 应用名称 |
| `SERVER_PORT` | `18080` | 后端 HTTP 端口 |

数据库配置：

| 配置项 | 示例 | 说明 |
|--------|------|------|
| `DB_HOST` | `127.0.0.1` | MySQL 地址 |
| `DB_PORT` | `3306` | MySQL 端口 |
| `DB_NAME` | `susumonitor` | 数据库名 |
| `DB_USER` | `susumonitor` | 数据库用户 |
| `DB_PASSWORD` | `732682` | 本机开发数据库密码 |
| `DB_CHARSET` | `utf8mb4` | 字符集 |
| `DB_TIMEZONE` | `Asia/Shanghai` | 数据库时区 |

认证和加密配置：

| 配置项 | 示例 | 说明 |
|--------|------|------|
| `JWT_SECRET` | `CHANGE_ME_LOCAL_JWT_SECRET` | JWT 签名密钥 |
| `JWT_EXPIRE_HOURS` | `24` | JWT 有效期，单位小时 |
| `AES_GCM_KEY` | `CHANGE_ME_LOCAL_AES_GCM_KEY` | SSH 凭据 AES-GCM 加密密钥 |
| `AGENT_REGISTER_KEY` | `CHANGE_ME_LOCAL_AGENT_REGISTER_KEY` | Agent 首次注册密钥 |

SSH 和调度配置：

| 配置项 | 示例 | 说明 |
|--------|------|------|
| `SSH_CONNECT_TIMEOUT_SECONDS` | `10` | SSH 连接超时 |
| `SSH_IDLE_TIMEOUT_MINUTES` | `20` | SSH 会话无输入超时 |
| `METRICS_RETENTION_DAYS` | `10` | 指标保留天数 |
| `METRICS_CLEANUP_CRON` | `0 0 3 * * ?` | 指标清理定时任务 |

## 五、安全要求

- `.env` 不提交 Git。
- `.env.*` 不提交 Git，`.env.example` 除外。
- `JWT_SECRET`、`AES_GCM_KEY`、`AGENT_REGISTER_KEY` 不允许硬编码。
- 日志不得输出数据库密码、JWT、Token、SSH 密码、SSH 私钥、AES 密钥、Agent 注册密钥。
- 本机开发密码 `732682` 不得用于生产环境。
- Java 代码必须遵循《阿里巴巴 Java 开发手册》。
