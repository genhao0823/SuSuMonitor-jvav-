### 2.5 四个遗留 Bug 复现原则

优先使用隔离库和已有测试数据进行真实 HTTP 复现；没有可用凭据或安全测试数据时，不执行会改变服务器数据的删除、更新或创建操作，并将结果标记为“运行时未验证”。源码和自动化测试只能作为静态/Mock 证据，不能替代真实 HTTP 复现。

四项检查：

| Bug | B0 判断标准 |
|---|---|
| `M4-server-list-sort-ignored` | 不同白名单排序参数返回顺序不同；非法参数返回 40002 |
| `M4-server-put-existence-check` | 不存在 ID 且请求体字段不完整时仍返回 40002，视为仍复现；返回 40400 才算修复 |
| `M4-ssh-test-error-code` | 不存在 ID 返回 40400；已存在服务器未确认主机指纹返回专用错误码；连接失败按分类错误码返回 |
| `M4-server-list-soft-delete` | 直接查 `deleted=0` 数量与列表 total 一致；已软删除 ID 的详情和状态均返回 40400 |
