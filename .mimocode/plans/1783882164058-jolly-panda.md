# 配置 MiMoCode 使用自定义 gpt-5.5 模型

## 现状

全局配置文件 `~/.config/mimocode/mimocode.jsonc` 中已存在 `pwn1` provider 配置：

```jsonc
{
  "provider": {
    "pwn1": {
      "name": "pwn1",
      "env": ["PWN1_API_KEY"],
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://sub.qlu.pwnyun.com/",
        "setCacheKey": true
      },
      "models": {
        "gpt-5.5": { "name": "gpt-5.5" }
      }
    }
  },
  "model": "pwn1/gpt-5.5"
}
```

配置已正确指向目标地址和模型，但缺少 API Key。

## 执行计划

### 步骤 1：设置 API Key 环境变量

在 `~/.config/mimocode/mimocode.jsonc` 的 `pwn1` provider 中直接嵌入 API Key（通过环境变量注入），或者更简单地：在系统环境变量中设置 `PWN1_API_KEY`。

**推荐方案：** 在全局配置中直接添加 `apiKey` 字段（更可靠）：

修改 `~/.config/mimocode/mimocode.jsonc`，将 `pwn1` 改为：

```jsonc
"pwn1": {
  "name": "pwn1",
  "apiKey": "sk-8f120b2f84b76e5d8a29b9a28246933d73a40f1ace035950bbc6e5d71908c627",
  "npm": "@ai-sdk/openai-compatible",
  "options": {
    "baseURL": "https://sub.qlu.pwnyun.com/",
    "setCacheKey": true
  },
  "models": {
    "gpt-5.5": { "name": "gpt-5.5" }
  }
}
```

移除 `env` 字段（不再需要从环境变量读取），直接用 `apiKey`。

### 步骤 2：验证

- 运行 `mimo providers` 确认 `pwn1` provider 已加载
- 运行 `mimo models` 确认 `gpt-5.5` 模型可用

## 涉及文件

- `~/.config/mimocode/mimocode.jsonc` — 全局配置文件（唯一修改）

## 注意事项

- API Key 将以明文存储在配置文件中，请确保该文件权限合理（仅当前用户可读）
- 如果 `@ai-sdk/openai-compatible` 包尚未安装，可能需要先安装：`npm install -g @ai-sdk/openai-compatible`
