# 修复 pwn1/gpt-5.5 模型配置

## 问题分析

1. **API Key 问题**（已解决）- pwn1 provider 的 API Key 已配置
2. **参数兼容性问题**（根本原因）- MiMoCode 的 `@ai-sdk/openai-compatible` SDK 发送 `max_output_tokens` 参数，但 pwn1 API 只支持 `max_tokens`

## 错误信息
```
Unsupported parameter: max_output_tokens
status 400 · non-retryable
```

## 当前状态
- 配置 schema 中没有找到可以切换参数名称的选项
- 这是 SDK 与 API 的兼容性问题，无法通过配置解决

## 解决方案

### 方案 1：使用内置 mimo provider（推荐）
- 已配置好 `mimo/MiMo-V2.5-Pro-UltraSpeed`
- 直接修改配置文件将 model 改为 `mimo/MiMo-V2.5-Pro-UltraSpeed`
- 立即可用，无需等待更新

### 方案 2：等待 MiMoCode 更新
- 等待官方添加对 `max_tokens` 的支持
- 或者添加配置选项让 provider 使用旧版参数

### 方案 3：联系 pwn1 平台
- 让他们支持 `max_output_tokens` 参数
- 这是 OpenAI 新版 API 的标准参数

## 推荐操作
修改 `~/.config/mimocode/mimocode.jsonc`：
```jsonc
{
  "model": "mimo/MiMo-V2.5-Pro-UltraSpeed"
}
```
